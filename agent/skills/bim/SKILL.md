# BIM / maquette 3D

Skill interne de Construction Agent (`bim`).

## Regles

1. Un .blend n'existe que s'il a ete ecrit et re-verifie sur disque.
2. Nommage : scene_<projet>.blend.
3. Documenter les objets crees et leur nombre.
4. Pas de calcul structurel reglementaire : HUMAN_GATE = REQUIRED.

## Preuve requise

Toute sortie de ce skill doit etre accompagnee d'un `evidence.json`
conforme au systeme Evidence (section 21 de la specification).
