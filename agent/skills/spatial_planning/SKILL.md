# Planification spatiale

Skill interne de Construction Agent (`spatial_planning`).

## Regles

1. Construire zoning, matrice d'adjacence, circulations.
2. Hierarchie : PUBLIC / PRIVE / SERVICE.
3. Verifier les relations verticales et interieur/exterieur.
4. Sortie : spatial_strategy.json avec statuts explicites.

## Preuve requise

Toute sortie de ce skill doit etre accompagnee d'un `evidence.json`
conforme au systeme Evidence (section 21 de la specification).
