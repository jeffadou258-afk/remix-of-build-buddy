# Documentation technique

Skill interne de Construction Agent (`documentation`).

## Regles

1. Distinguer CONCEPTUAL vs ENGINEERED / VERIFIED.
2. Ne jamais inventer une reglementation. Si aucune source : REGULATION_STATUS = UNKNOWN.
3. Chaque document liste ses hypotheses et ses donnees UNKNOWN.
4. Historiser : hypotheses, decisions, revisions.

## Preuve requise

Toute sortie de ce skill doit etre accompagnee d'un `evidence.json`
conforme au systeme Evidence (section 21 de la specification).
